#connnect_four_game_project

Developed an interactive Connect Four game with a Prolog-based game engine and AI opponent using Minimax with configurable search depth.
Built a FastAPI backend to bridge the web interface with Prolog, handling player moves, AI decisions, win detection, and draw conditions.
Designed a responsive HTML/CSS/JavaScript interface with real-time board updates, move animations, game status, and adjustable AI difficulty.
